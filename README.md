# Student Grade Tracker

## Task 1 – Code Alpha Java Programming Internship

### Project Description
Student Grade Tracker is a console-based Java application used to input, manage, and analyze student grades. It calculates the average, highest, and lowest scores and displays a summary report of all students.

### Features
- Add student names and marks.
- Store student records using ArrayList.
- Calculate average marks.
- Find the highest score.
- Find the lowest score.
- Display a summary report of all students.
- Simple menu-driven console interface.

### Technologies Used
- Java
- ArrayList
- Scanner
- Object-Oriented Programming (OOP)

### How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the Java file:

   ```bash
   javac StudentGradeTracker.java
   ```

5. Run the program:

   ```bash
   java StudentGradeTracker
   ```
